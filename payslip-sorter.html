Payslip Sorter

Sort each month's payslips into one folder per home, check them against the payroll summary, and download a pack for each manager.

Your files are processed on this device and never uploaded. Nothing is sent anywhere or saved. Closing or refreshing this page clears them.

How to use

  1. 1
    Add the payroll summary

    The Excel file with an Employee column and a House column (Home, Department or Site also work). Last month's summary is optional.

  2. 2
    Add the payslip PDFs

    One big PDF from the payroll software, or several split files. Duplicates and pages in the wrong file are fine.

  3. 3
    Check, then download

    Read the issues, file any leftover pages by hand, then download everything or one ZIP per home for each manager.

        Add the payroll summary and at least one payslip PDF.

            Homes

            Payslip Sorter reads the text inside the PDFs to find each person's name and net pay. Scanned or photographed payslips (images with no text) can't be read; export them from the payroll software instead.

            The payroll summary decides which home each person belongs to. Password-protected PDFs need an unprotected copy.
